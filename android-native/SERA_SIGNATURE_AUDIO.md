# SERA Signature notification audio

Five original synthesized mono PCM WAV assets, 22,050 Hz, 16-bit. No samples or third-party recordings. Short sine-based chimes with harmonic partials, attack and decay envelopes; durations 0.30–0.98 seconds. Created for SERA.et. The source note sequences are documented in this file.

Pulse: 660/880 Hz; Opportunity: 523.25/659.25/783.99 Hz; Connect: 587.33/739.99 Hz; Social: 830.61 Hz; Attention: 440/659.25/523.25 Hz. All assets are newly synthesized, not copied from existing notification tones.

The default mode preserves the existing Android channel; Signature and Silent are explicit device-level choices. Android channel settings remain authoritative.
