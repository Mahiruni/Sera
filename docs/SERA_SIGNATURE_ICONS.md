# Sera Signature Icons

The native package-local adapter replaces common Material vector action glyphs with a shared 24-unit grid, 1.8-unit rounded strokes and existing theme tint. The five existing footer shapes are retained exactly. Messaging, call controls, attachments, composer tools, profile and navigation, job and post actions using the adapter inherit the same visual language. Original content descriptions and button touch targets remain unchanged. Unknown specialized vectors, platform/notification glyphs, brand images and painters deliberately retain their original visual. Web Lucide and signature reaction glyphs inherit the same stroke style. No additional font, icon library or network dependency is introduced.

QA: verify mapping and accessibility, then inspect native screenshots in both themes and check actual signed upgrade. Existing custom artwork and feature-specific icons may need a later per-screen audit; no claim of exhaustive pixel parity is made.
