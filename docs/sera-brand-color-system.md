# Sera brand color contract

Visible brand: Sera (sera.et only as a domain).

- Primary teal: #0D7C86 — main actions, navigation, identity.
- White: #FFFFFF — light surfaces.
- Activity purple: #7C3AED — unread counts, notification badges, repost activity and attention accents. Use #C4B5FD for dark-mode text on dark surfaces. Keep white on solid purple badges.

Use purple intentionally for activity, not for primary actions or every decorative surface. Soft teal #E5F4F2 is a surface tint, not a replacement for the third brand color.

Review every web and Android UI change for correct role usage, contrast, light/dark rendering, and consistent branding. No additional languages beyond English, Amharic and Afaan Oromo for new UI.
