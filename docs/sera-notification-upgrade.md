# Sera notification upgrade

Android private notifications use authenticated sender identity, native MessagingStyle, initials/photo fallback and account-scoped in-memory history. Existing preview-off accounts remain hidden; new accounts default to full previews. Change settings in Messaging control center > Notifications & privacy. Android public lock-screen content remains generic.

Web push uses Firebase's existing FCM sender and token registry. Set server environment FIREBASE_WEB_CONFIG_JSON (public Firebase web app configuration, not service-account credentials) and FIREBASE_WEB_VAPID_KEY (public web-push key). The browser must support service workers and push and must grant notification permission from the settings button. No secret is included in the worker. Private sender details and text are fetched from the recipient-authorized no-store endpoint, not from FCM. Existing registered native devices are unaffected. Closed-browser delivery depends on browser and operating-system support. Validate a real web subscription and cross-device delivery before claiming production readiness.
